# Diabetes Readmission Prediction 📊

This repository contains my data science project focused on **Diabetes Readmission Prediction**. 

## 📂 Included Project Files
- `HOSPITAL DIABETES READMISSON PRED.ipynb`

## ⚙️ Tech Stack & Concepts
- **Programming Language:** Python
- **Libraries & Tools:** Jupyter Notebooks, Pandas, NumPy, Scikit-Learn
- **Core Concepts:** Data analysis, feature engineering, model training, and performance evaluation.

## 🚀 How to Run
1. Clone the repository:
   ```bash
   git clone https://github.com/arunak451/diabetes-readmission-prediction.git
   ```
2. Install dependencies:
   ```bash
   pip install jupyter pandas numpy scikit-learn
   ```
3. Open Jupyter Notebook:
   ```bash
   jupyter notebook
   ```
4. Run the notebooks to explore the models and classification results.
